# Data

The single-cell RNA-seq data used in this analysis were obtained from
[PanKbase](https://data.pankbase.org/).

The analysis is based on the PanKbase resource analysis set
[PKBDS1349YHGQ](https://data.pankbase.org/analysis-sets/PKBDS1349YHGQ/).

The associated PanKbase matrix-file entry is
[PKBFI5903OGWY](https://data.pankbase.org/matrix-files/PKBFI5903OGWY/).

The analyses in this repository use the local Seurat object:

`060425_scRNA_v3.3.rds`

The large Seurat object is not redistributed through this GitHub repository.

To run the workflow, place the RDS file in this directory or specify its
location using `data_file` in `config/local_paths.R`.
