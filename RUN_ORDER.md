# Suggested run order

The R workflow was developed interactively. Run `00_setup.R` once and then
execute the numbered R scripts sequentially in the same R session.

1. `scripts/00_setup.R`
2. `scripts/01_celltype_overview.R`
3. `scripts/02_SCN_family_expression.R`
4. `scripts/03_pseudobulk_DESeq2.R`
5. `scripts/04_targeted_SCN_pseudobulk.R`
6. `scripts/05_SCN9A_beta_cell_association.R`
7. `scripts/06_GSEA_and_functional_modules.R`
8. `scripts/07_CytoTRACE2.R`
9. `scripts/08_SCENIC_prepare.R`
10. Activate the pySCENIC conda environment and run `scripts/09_run_pyscenic.sh`
11. `scripts/10_SCENIC_downstream.R`
12. Run `scripts/python/11_export_regulon_targets.py`
13. `scripts/12_SCENIC_networks_and_exploratory_monocle3.R`
14. `scripts/13_monocle2_pseudotime.R`

Notes:
- Script 03 is the broad transcriptome-wide pseudobulk workflow for both HbA1c and diabetes-status groupings.
- Script 04 is a targeted SCN-family/TRPC4 workflow with richer donor covariates and focused SCN9A/TRPC4 outputs.
- Script 06 uses objects created in the SCN9A association workflow.
- SCENIC downstream scripts use files generated by the shell/Python steps.
- The final regulon-pseudotime panels in script 13 use SCENIC objects created earlier in the same R session.
